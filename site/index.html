How it is intended to work

Verse retrieval meets a conversational interface.

The repository pairs a FastAPI application with local verse embeddings, Groq for answer generation, and Supabase for authentication and persistence.

Those backend connections and generated answers have not been exercised in this environment.

Current boundary

This page is a static presentation.

It does not provide sign-in, chat, verse retrieval, or database access. The actual application is a separate FastAPI project that needs configured services and a compatible Python runtime.
